# Portafolio · Next.js + React + Tailwind CSS 4.1 + JavaScript

## Iniciar
    npm install
    npm run dev      # http://localhost:3000

## Personalizar
- Todo el contenido (nombre, proyectos, experiencia, hobbies...) está en `data/data.js`.
- Iconos propios: edita `components/Icon.js` (SVG de 24x24 por entrada).
- Capturas de proyectos: guarda imágenes en `public/projects/` y agrega `image: "/projects/mi.png"` al proyecto.
- CV: coloca tu archivo en `public/cv.pdf`.
- Colores: variables al inicio de `app/globals.css`.
- Formulario: conéctalo a Formspree/EmailJS en `components/Contact.js`.

## Publicar
Sube el repositorio a GitHub e impórtalo en Vercel.
